# M2 — соответствие фотографии заявленной категории

Zero-shot через `openai/clip-vit-base-patch32` (151M): изображение
сопоставляется с текстовым описанием категории, поэтому новая категория
добавляется строкой в [catalog.json](../catalog.json), а не переобучением.

## Запуск

```bash
.venv/bin/python m2_image/predict.py --list-categories
.venv/bin/python m2_image/predict.py --image фото.jpg --category "Спорт: мячи"
.venv/bin/python m2_image/evaluate.py --limit 500 --perf-devices mps cpu
```

Тестовый набор скачивается один раз:

```bash
.venv/bin/python m2_image/download_data.py
```

## Результаты

| Модель | Вариантов | top-1 | top-3 |
|---|---|---|---|
| CLIP zero-shot | 23 + 3 дистрактора | 0.966 | 0.998 |
| ResNet50 обученный | 10 классов | 0.998 | — |

Решение по заявленной категории (allow / review / reject) считается той же
функцией `decide`, что и в `predict.py`:

| | allow | review | reject |
|---|---|---|---|
| честные объявления | 96.0% | 1.6% | 2.4% |
| подменённая категория | 0.2% | 1.6% | 98.2% |

Подмена не проходит в публикацию в 99.8% случаев,
precision(reject) 0.976. Подменная категория назначается сдвигом
по справочнику и обычно визуально далека от истинной — это оценка для грубой подмены.

## Что важно знать

- **Цена универсальности — 3.2 п.п.**, и она растёт с размером каталога.
- **Батчинг даёт больше, чем GPU**: 2.6x от батчинга против 1.5x от MPS.
- Эмбеддинги категорий считаются один раз при инициализации.
