# M3 — распознавание речи в голосовых комментариях

`whisper-small` в int8 через faster-whisper (244M). Расшифровка передаётся
в M1: без этого нарушения в голосовых не отлавливаются вообще.

## Запуск

```bash
.venv/bin/python m3_audio/make_testset.py
.venv/bin/python m3_audio/transcribe.py --audio запись.wav --moderate --srt
.venv/bin/python m3_audio/evaluate.py --sizes tiny base small
.venv/bin/python m3_audio/measure_snr.py        # фактический SNR шумных записей
```

## Результаты

| Условие | WER | RTF | Согласованность вердиктов |
|---|---|---|---|
| чистая запись | 0.065 | 0.269 | 93.3% |
| умеренный шум, ~13 дБ | 0.194 | 0.266 | 93.3% |
| сильный шум, ~7 дБ | 0.406 | 0.269 | 80.0% |

## Что важно знать

- **Главная метрика — не WER, а согласованность вердиктов**: доля записей, где
  решение M1 по расшифровке совпало с решением по эталону. При умеренном шуме
  WER вырос втрое, а согласованность не изменилась: модель путает окончания,
  но оскорбление остаётся оскорблением. При сильном шуме согласованность падает
  до 80% — ошибки начинают уничтожать ключевые слова, критерий ТЗ (≥ 90%)
  не выполнен.
- Уровень шума задан амплитудой генератора; имена `noisy15`/`noisy10` условные,
  фактический SNR измеряет `measure_snr.py`.
- Тестовый набор синтезирован системным голосом macOS — эталонный текст известен
  точно, но такая речь чище живой, и WER занижен.
- CTranslate2 не поддерживает Metal, модель работает на CPU.
