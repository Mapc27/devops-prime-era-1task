# M4 — проверка видеообзора товара

`yolo11n` через Ultralytics (2.6M, 80 классов COCO). Анализируется каждый
5-й кадр.

## Запуск

```bash
.venv/bin/python m4_video/detect_video.py --list-categories
.venv/bin/python m2_image/download_data.py      # исходные фото — Imagenette
.venv/bin/python m4_video/prepare_frames.py
.venv/bin/python m4_video/make_testset.py
.venv/bin/python m4_video/detect_video.py --video обзор.mp4 \
    --category "Животные: собаки" --save
.venv/bin/python m4_video/evaluate.py --models yolo11n.pt yolo11s.pt \
    --devices mps cpu --strides 1 5 10 15
```

## Результаты

| Шаг кадров | accuracy | подмены пойманы | время, с |
|---|---|---|---|
| 1 | 0.875 | 1.000 | 27.0 |
| **5** | **0.875** | **1.000** | **5.8** |
| 10 | 0.833 | 1.000 | 3.3 |
| 15 | 0.833 | 1.000 | 2.6 |

Шаг 5 выбран по данным: качество то же, что при полном переборе, времени
в 4.7 раза меньше. Время — за полный проход по 24 проверкам.

## Что важно знать

- **Модель знает ровно то, чему её учили.** Класс COCO `sports ball` обучен
  на футбольных и теннисных мячах — гольфовый уходит в `apple` и `frisbee`
  (1 из 4 роликов). Из 23 категорий справочника видеомодуль проверяет 16.
- Объект засчитывается только если найден минимум в 3 кадрах — защита
  от единичных ложных срабатываний.
- Ролики тестового набора собраны из фотографий Imagenette наездом камеры,
  метрики оптимистичны. Подменная категория назначается сдвигом по справочнику
  и визуально далека от истинной, поэтому 100% пойманных подмен — простая
  часть задачи.
